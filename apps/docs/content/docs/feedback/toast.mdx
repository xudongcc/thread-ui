## API Style

`Toast` uses a [function-based API](/docs/api-design/function-based). Mount
`ToastProvider` once, then call the toast manager from event handlers and async
workflows.

## Installation

```bash
pnpm dlx shadcn@latest add @thread-ui/toast
```

## Setup

Add the `ToastProvider` to your root layout:

```tsx
import { ToastProvider } from "@/components/thread-ui/toast";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <ToastProvider>{children}</ToastProvider>
      </body>
    </html>
  );
}
```

## Usage

### Function API

```tsx
import { toast } from "@/components/thread-ui/toast";
```

```tsx
toast.add({ title: "Event has been created." });
```

## Features

- **Multiple Types**: Support for default, success, info, warning, and error toasts
- **Promise Support**: Show loading, success, and error states for async operations
- **Actions**: Add interactive buttons to toasts
- **Auto Dismiss**: Toasts automatically dismiss after a configurable duration
- **Accessible**: Follows WAI-ARIA guidelines for notifications

## Best Practices

- Use success toasts to confirm completed actions
- Use error toasts for failures that need user attention
- Keep toast messages concise and actionable
- Use descriptions sparingly for additional context
- Avoid stacking too many toasts at once

### Toast Manager

The exported manager supports adding, updating, closing, and tracking promise
toasts:

```tsx
// Add a toast
const id = toast.add({ title: "Hello World" });

// With options
toast.add({
  title: "Event created",
  description: "Your event has been created successfully.",
  actionProps: {
    children: "Undo",
    onClick: () => console.log("Undo"),
  },
});

// Different types
toast.add({ title: "Success!", type: "success" });
toast.add({ title: "Something went wrong", type: "error" });
toast.add({ title: "Did you know?", type: "info" });
toast.add({ title: "Be careful!", type: "warning" });

// Update or close a toast
toast.update(id, { description: "Updated" });
toast.close(id);

// Promise toast
toast.promise(saveData(), {
  loading: "Saving...",
  success: "Data saved!",
  error: "Could not save",
});
```

### Provider Options

Configure the default timeout and maximum visible toast count on the provider:

```tsx
<ToastProvider timeout={5000} limit={3}>
  {children}
</ToastProvider>
```
