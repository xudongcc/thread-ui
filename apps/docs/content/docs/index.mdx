## Introduction

Thread UI is a component library built on top of [shadcn/ui](https://ui.shadcn.com) and [Base UI](https://base-ui.com). It provides accessible, customizable components that extend the shadcn/ui ecosystem with additional functionality powered by Base UI primitives.

## Installation

### New Projects

Create a new project with the same Base UI theme preset used by Thread UI:

```bash
pnpm dlx shadcn@latest init --base base --preset b1au7YYAi
```

The preset selects the Rhea component style with neutral base colors and a blue
theme. The `--base base` option selects Base UI primitives.

### Existing Projects

Apply the same preset to an existing shadcn/ui project that uses Base UI:

```bash
pnpm dlx shadcn@latest apply --preset b1au7YYAi
```

The resulting `components.json` uses:

```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "base-rhea"
}
```

Applying a preset reinstalls existing shadcn/ui components and updates theme
variables. Commit or stash local component customizations before running it.

## Adding Components

### Install the Thread UI theme

After initializing shadcn/ui with Tailwind CSS v4, install the shared theme:

```bash
pnpm dlx shadcn@latest add @thread-ui/default-theme
```

This merges the light/dark colors, radius scale, `bg-canvas` utility mapping,
base styles, and Topbar appearance scopes into the CSS file configured in
`components.json`. It also sets the body background to `bg-canvas`.
The theme is generated from the same `themes/default-theme/default.css` used by our
applications, so it includes the Neutral secondary colors shown in Storybook.

No `@repo/default-theme` package or additional CSS import is needed. The theme keeps
your existing fonts and component style; use the preset above for Rhea and Inter.
Installing the theme updates matching theme tokens across the application.
Changes remain local to your project; rerun the command to install theme updates.

Install the theme once before adding Layout, which uses `bg-canvas`.
The former `@thread-ui/theme` entry has been removed; use
`@thread-ui/default-theme` for future installations and updates. Existing
installed CSS remains valid.

### Install a component

Thread UI is a trusted registry for shadcn/ui. Add components using the CLI:

```bash
pnpm dlx shadcn@latest add @thread-ui/badge
```

This will automatically add the Thread UI registry to your `components.json`:

```json
{
  "registries": {
    "@thread-ui": "https://thread-ui.vercel.app/r/{name}.json"
  }
}
```

## Why Base UI?

The `base-rhea` style uses [Base UI](https://base-ui.com) as the underlying component library, providing:

- **Better Accessibility** - Built with ARIA best practices from the ground up
- **Flexible APIs** - More control over component behavior and styling
- **Modern Architecture** - Designed for React 18+ with concurrent features support

For more information, visit the [Base UI documentation](https://base-ui.com).
