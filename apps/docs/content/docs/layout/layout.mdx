## Installation

```bash
pnpm dlx shadcn@latest add @thread-ui/default-theme
pnpm dlx shadcn@latest add @thread-ui/layout @thread-ui/sidebar-account-menu
```

## Composition API

`Layout` provides `SidebarProvider` with a fixed viewport height. Compose
`LayoutSidebar` and `LayoutContent` directly, including through fragments or custom
components. Place branding in `SidebarHeader`, existing navigation in
`SidebarContent`, and `SidebarAccountMenu` in `SidebarFooter`.

```tsx
import { ShoppingBagIcon } from "lucide-react";
import {
  Layout,
  LayoutContent,
  LayoutSidebar,
} from "@/components/thread-ui/layout";
import { Page } from "@/components/thread-ui/page";
import { SidebarAccountMenu } from "@/components/thread-ui/sidebar-account-menu";
import {
  SidebarHeader,
  SidebarContent,
  SidebarFooter,
  SidebarMenu,
  SidebarMenuItem,
  SidebarMenuButton,
  SidebarTrigger,
  useSidebar,
} from "@/components/ui/sidebar";

import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip";

function Navigation() {
  const { isMobile, open, setOpenMobile } = useSidebar();
  const label = open ? "Collapse navigation" : "Expand navigation";
  return (
    <LayoutSidebar collapsible="icon">
      <SidebarHeader>
        <div className="flex items-center gap-2">
          <span
            aria-hidden="true"
            className="group-data-[collapsible=icon]:hidden"
          >
            T
          </span>
          <span className="min-w-0 flex-1 truncate group-data-[collapsible=icon]:hidden">
            Thread UI
          </span>
          {!isMobile && (
            <Tooltip>
              <TooltipTrigger
                render={<SidebarTrigger aria-label={label} size="icon" />}
              />
              <TooltipContent side="right">{label}</TooltipContent>
            </Tooltip>
          )}
        </div>
      </SidebarHeader>
      <SidebarContent>
        <nav aria-label="Navigation">
          <SidebarMenu>
            <SidebarMenuItem>
              <SidebarMenuButton
                aria-label="Orders"
                tooltip="Orders"
                render={<a href="/orders" />}
                onClick={() => {
                  if (isMobile) setOpenMobile(false);
                }}
              >
                <ShoppingBagIcon aria-hidden="true" />
                <span className="group-data-[collapsible=icon]:hidden">
                  Orders
                </span>
              </SidebarMenuButton>
            </SidebarMenuItem>
          </SidebarMenu>
        </nav>
      </SidebarContent>
      <SidebarFooter>
        <SidebarAccountMenu
          user={{
            name: "Alex Morgan",
            email: "alex@example.com",
            render: <a href="/profile" />,
          }}
        />
      </SidebarFooter>
    </LayoutSidebar>
  );
}

<Layout>
  <Navigation />
  <LayoutContent>
    <Page>{/* Page content */}</Page>
  </LayoutContent>
</Layout>;
```

Layout does not generate navigation. Compose shadcn sidebar groups, menu items,
and badges as needed. Framework links use the menu button's native `render` prop.
After accepting navigation, call `setOpenMobile(false)` to dismiss the drawer.

## Layout and scrolling

The sidebar spans the full height beside the main content. Use
`<LayoutSidebar collapsible="icon">` with the default sidebar variant. `LayoutContent`
renders the native `SidebarInset` as its outer element, but its inset styling is
only activated by `variant="inset"`. With the default variant, content fills the
available space without outer margins, rounded corners, or a shadow. shadcn
handles the sidebar border and collapsed width.

`Layout` uses `bg-sidebar`; `LayoutContent` uses `bg-canvas`. Customize the existing
`--sidebar` and `--canvas` theme tokens independently. Omitting Sidebar lets content
fill the available width. For a right-side Sidebar, compose
LayoutContent before `<LayoutSidebar side="right">` to match the native flex layout.

`LayoutContent` composes Base UI ScrollArea with shadcn scrollbars. SidebarInset is
the single `main` landmark; its scrolling viewport is a div. Native attributes,
`ref`, and `className` apply to the outer main element; `onScroll` applies to the
inner viewport (`data-slot="layout-content-viewport"`). Use one LayoutContent per
Layout. Its optional `id` is also used by the keyboard skip link. Put `Page` and
`PageLayout` inside it to organize content. Tables can retain their own horizontal
scrolling.

`Layout` accepts native div attributes, refs, classes, and styles. Set
`--sidebar-width` through `style` to customize sidebar width. The default height
is `100svh`; the native desktop sidebar is fixed to the viewport.

## Collapsing and mobile

Use `<LayoutSidebar collapsible="icon">` for a desktop icon rail. The default is
expanded. Compose shadcn `SidebarTrigger` with `Tooltip` in SidebarHeader. It stays
visible on desktop, including the collapsed rail. Set `aria-label` and tooltip
text to the same translated action label. The example uses `layout.expandNavigation`
and `layout.collapseNavigation` from the locale dictionary.
Add `tooltip` and `aria-label` to icon-only navigation buttons, and hide custom
text with `group-data-[collapsible=icon]:hidden`. SidebarAccountMenu automatically
reduces its default trigger to the avatar.

Below 768px, Sidebar opens as the existing shadcn Sheet with Escape/outside-click
dismissal and focus management. `LayoutSidebar` automatically enables a floating shadcn `SidebarTrigger`
using its built-in accessible text, without an extra Tooltip or `aria-label`. The button uses native
`variant="outline"` and `size="icon-lg"` (36px) and is fixed to the bottom-left corner, with a 16px gap plus device safe-area insets. It
stays visible while content scrolls and sits below the drawer overlay.

`LayoutContent` keeps the viewport full-height and automatically adds 80px plus the
bottom safe-area inset as padding to its inner scrolling content. The button and
padding are both disabled on desktop. No extra button or spacer is needed in pages.

`LayoutSidebar` accepts the native shadcn Sidebar props and children, including
`side`, `variant`, `collapsible`, and `className`. Continue using shadcn
`SidebarHeader`, `SidebarContent`, and `SidebarFooter` inside it. Floating navigation
and content spacing are coordinated automatically through Layout.

When LayoutSidebar is omitted or unmounted, both the floating button and its
content padding are removed. A non-collapsible sidebar (`collapsible="none"`)
also leaves them disabled. You can use the original shadcn Sidebar when you need
to implement mobile navigation yourself.

```tsx
<Layout>
  <LayoutContent>
    <Page>{/* Content without a sidebar */}</Page>
  </LayoutContent>
</Layout>
```

Layout closes the drawer when returning to desktop. The user menu remains in the
drawer footer.

## Examples

Storybook includes a dashboard, Page/DataFilter/DataTable orders, a two-column
collection editor, and a layout without a sidebar. Use viewport, theme and
language toolbars to inspect responsive behavior.
