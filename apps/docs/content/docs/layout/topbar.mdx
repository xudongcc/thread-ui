title: Topbar
description: Responsive top bar with composable branding, navigation, and account controls.
---

## Installation

```bash
pnpm dlx shadcn@latest add @thread-ui/topbar
```

## Composition API

Compose the header with `TopbarBrand`, `TopbarSidebarTrigger`,
`TopbarActionGroup`, `TopbarAction`, and `TopbarMenu`. Arrange or omit parts to
suit the application. The navigation trigger connects to shadcn Sidebar; the host
owns navigation items and account actions.

```tsx
import { BellIcon } from "lucide-react";
import {
  Topbar,
  TopbarBrand,
  TopbarSidebarTrigger,
  TopbarActionGroup,
  TopbarAction,
  TopbarMenu,
  TopbarMenuTrigger,
  TopbarMenuContent,
  TopbarMenuUser,
  TopbarMenuSeparator,
  TopbarMenuItem,
} from "@/components/thread-ui/topbar";

// Inside Layout or SidebarProvider:
<Topbar>
  <TopbarSidebarTrigger />
  <TopbarBrand>Thread UI</TopbarBrand>
  <TopbarActionGroup>
    <TopbarAction aria-label="Notifications" onClick={openNotifications}>
      <BellIcon />
    </TopbarAction>
  </TopbarActionGroup>
  <TopbarMenu user={user}>
    <TopbarMenuTrigger />
    <TopbarMenuContent>
      <TopbarMenuUser onClick={openProfile} />
      <TopbarMenuSeparator />
      <TopbarMenuItem onClick={signOut}>Sign out</TopbarMenuItem>
    </TopbarMenuContent>
  </TopbarMenu>
</Topbar>;
```

`Topbar` accepts children, optional `variant`, and native header attributes,
including `ref`, `className`, and `style`. CSS Grid lets the first visible child's
column absorb remaining space; branding and navigation align left, while actions
and account controls align right. Parts can be omitted without placeholder
elements. Its default height is 56px, with a
bottom border. Custom content such as a search field can be placed directly
among its children. Topbar itself does not require a provider;
`TopbarSidebarTrigger` requires `SidebarProvider`, which Layout supplies.

## Parts

- `TopbarBrand`: site name and optional logo. Hidden below 768px.
- `TopbarSidebarTrigger`: a 40px mobile navigation button with a built-in
  icon, translated accessible label, and sidebar toggle. Hidden on desktop.
  Use `<TopbarSidebarTrigger />` inside Layout or SidebarProvider. It accepts
  Button props, including `render`, `ref`, and `disabled`. An optional `onClick`
  runs before toggling; call `event.preventDefault()` to cancel the toggle.
- `TopbarActionGroup`: aligns action buttons to the right.
- `TopbarAction`: Button with a 40px icon-button default and styles that follow
  the header appearance. Supports Button props including `render`, `ref`,
  `disabled`, and `loading`. Supply an accessible label for icon-only actions.

The brand and action group forward native div attributes,
refs, and classes. Parts can be wrapped in fragments or custom components.

## Appearance

Omit `variant` to follow the application theme: white with dark text in light
mode, and dark with white text in dark mode. Changes to the global `.dark` class
apply immediately. Use `variant="light"` or `variant="dark"` to fix the header
appearance independently of the global theme.

```tsx
<Topbar>{children}</Topbar>
<Topbar variant="light">{children}</Topbar>
<Topbar variant="dark">{children}</Topbar>
```

Actions and the TopbarMenu trigger adapt their hover, focus, and expanded styles.
The menu trigger becomes a circular avatar button below 640px.

The header and menu trigger use `bg-topbar`: white in light mode and Neutral 900 in dark mode.
Customize `--topbar` independently of the sidebar, canvas, and `--background`.
Both the theme registry and standalone Topbar installation include this token
and its Tailwind mapping.

For its other colors, Topbar reuses `--background`, `--foreground`,
`--accent`, `--accent-foreground`, `--border`, and `--ring`. Actions and the menu
trigger use the same accent treatment as other components.

Without a variant, it inherits the application's theme, including custom colors.
An explicit `variant` applies the existing light or dark theme variables locally
through `[data-slot="topbar"][data-variant="light"]` or
`[data-slot="topbar"][data-variant="dark"]`. The registry includes these scoped
rules without changing the consumer's global theme. Customize them alongside
`:root` and `.dark` in your stylesheet when changing the fixed appearances.
Menu popups are portaled and continue to use the page theme.

## Site logo

Place the logo and site name inside `TopbarBrand`. Mark decorative SVGs with
`aria-hidden="true"`. The **With Logo** Storybook example uses the Thread UI logo
and name, matching Layout. The whole brand is hidden on mobile.

## Layout integration

Place Topbar directly inside Layout, alongside shadcn Sidebar and LayoutContent.
Use `<TopbarSidebarTrigger />` to control the mobile drawer through Layout's
SidebarProvider. No additional button, icon, or hook is needed.

See [TopbarMenu](/docs/layout/topbar-menu) for workspace selection, user identity,
language/theme preferences, and framework links. Storybook lists **Topbar** and
**TopbarMenu** as siblings under **Layout**.
